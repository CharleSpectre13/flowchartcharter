# FlowChartCharter Engineering

## Core Mandate
Build **execution-and-quality-first** multi-agent systems where a versioned, glanceable **Charter** (state-chart map) owns the journey from start to launch. Agents follow pre-drawn paths; they do not search open graphs under pressure.

Graph elements (GraphRAG Local/Global/DRIFT) are **callable sub-flow tools** when pure relational discovery is required. The sequential Charter remains the permanent owner of the workflow.

## Contrast (Locked)

| Dimension | GraphRAG family | FlowChartCharter |
|-----------|-----------------|------------------|
| Primary paradigm | Retrieval-first passive lookup | Execution-and-quality-first actionable state-chart |
| Indexing | Extreme / full rebuild | Near-zero; incremental delta-state |
| Latency focus | Multi-hop traversal | Deterministic super-step edge routing |
| Agent model | Passive context | Corporate hierarchy + Blackboard volunteer |
| Engineer role | Always in the loop | Muscle-memory → Coach Trust Hand-Off |

## Five Foundational Units
1. **Charter** — versioned glanceable sequential map owning the full timeline
2. **Flow units** — named steps with typed I/O, exit criteria, rhythm markers
3. **Rhythm markers** — structural cues for one-glance context pulls
4. **Muscle-memory loop** — repeated runs + checkpoint history harden the path
5. **Engineer exit / Coach Trust Hand-Off** — designed hand-off when quality gates pass

## Enterprise Layers (Required)
- **Governance**: Executive Board & Boss Agent (GM) — budget, goals, downtime syncs
- **Charter**: CentralCharterGraph schema (LangGraph StateGraph + Pydantic)
- **State**: Channel reducers (deterministic merge, no races)
- **Execution**: BSP / Pregel super-step engine + Position Managers / Key Players
- **Memory**: Shared Blackboard (MCP-style) for volunteer task binding
- **Persistence**: Thread checkpointer (Postgres/Redis) for muscle-memory + recovery
- **Talent**: Promotion / demotion / decommission + Monday Morning Sync

## Seven-Phase Lifecycle (ST-01 … ST-07)
1. Charter Init & Intake (Board + Boss)
2. Voluntary Flow Binding (capability × rank match)
3. Parallel Super-Step Execution (BSP + reducers)
4. Rhythm Marker Audit Gate (exit criteria, e.g. score ≥ 0.90)
5. Muscle-Memory Remediation Loop (checkpoint RAG + patch)
6. Synthesis & Coach Trust Hand-Off
7. Downtime Team Sync & Org Optimization

## Design Principles
- Latency and cost are first-class metrics
- Pre-chartered sequential ownership over open relational surfaces
- Autonomy is engineered (muscle-memory stage required)
- Maker-checker: independent Audit Manager ≠ implementor agents
- Hybrid: invoke graph/RAG only when charter branches to discovery
- Continuous-team-audit-loop after every meaningful charter change
- Loop-engineer taxonomy for all self-running engineering cycles

## Fitness (Talent Management)
```
F = α·Quality + β·Rhythm − γ·Cost + δ·Synergy
```
Default weights: α=0.4, β=0.3, γ=0.001, δ=0.2. Promote if F ≥ 1.2× benchmark; fire if F < 0.7× benchmark.

## Integration Rules
- SDD six-element SPEC + constitution before non-trivial code
- advanced-agent-builder 5 subsystems + OWASP agentic controls

- loop-engineer for downtime sync, reindex, and continuous learning loops
