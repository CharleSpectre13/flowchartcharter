# FlowChartCharter Constitution

Immutable principles governing every specification, agent, loop, and repository in the FlowChartCharter open design.

## Article I — Primacy of the Charter
1. A versioned Charter owns the journey from start to launch.
2. Agents **follow rather than search** under time pressure.
3. GraphRAG / graph tools are callable sub-flows only when the Charter explicitly branches to relational discovery.
4. The Charter acts as quantum measurement operator \(M\) collapsing path superposition to deterministic action.

## Article II — Execution and Quality First
1. Optimize for fastest reliable path to execute, not passive retrieval completeness.
2. Latency, token cost, quality score, and synergy (entanglement) are first-class metrics.
3. Exit criteria are falsifiable numeric gates (default quality ≥ 0.90).
4. Scale is measured by **agents-on-charter** and **human-out-of-loop time**.

## Article III — Corporate Hierarchy
1. CEO, CFO, Board + Boss Agent (GM) govern strategy, budget, and downtime syncs.
2. Position Managers and Key Players execute flow units under typed contracts.
3. Talent is dynamic: promote, retain, demote, or decommission by fitness equation.
4. Free-form inter-agent chat is forbidden; Blackboard uses strict JSON performance vectors only.

## Article IV — Foundational Structures (DNA)
1. **Charter** · **Flow Units** · **Rhythm Markers** · **Muscle-Memory Loop** · **Coach Trust Hand-Off** · **Monday Morning Sync**.
2. Rhythm Markers are independent maker-checker validators (never the implementor).
3. Muscle-Memory supplies amplitudes \(c_i\) for quantum path selection.

## Article V — Muscle Memory and Coach Trust
1. Every successful run hardens muscle-memory weights via checkpointers.
2. Coach Trust Hand-Off is earned when stability and quality gates pass (Board GovernanceVector).
3. The System Engineer (Head Coach) exits the live loop; the Charter continues.

## Article VI — Safety and Verification
1. Maker-checker separation: implementors never sole-verify their own output.
2. Secondary goal verifier on high-impact mutations and charter patches.
3. Hard stop conditions, budgets, and blast-radius limits on all autonomous loops.
4. OWASP Agentic Top 10 controls apply to every agent role.

## Article VII — Continuous Learning & Graph Memory
1. continuous-team-audit-loop after every meaningful engineering step.
2. Downtime Monday Morning Sync (async RLAIF) raises benchmarks when queues are low.
3. Known-failures and decisions-log are external durable memory; context windows are not.
4. Brain 1 hierarchical knowledge graph holds domain ontology; GraphRAG is sub-flow only.

## Article VIII — Spec-Driven Development
1. Non-trivial work requires six-element executable SPEC + this constitution.
2. Code that drifts from approved contracts is rejected (CDR target 0%).
3. Open design: public repos, clear licenses, reproducible examples.

## Article IX — Forbidden Patterns
- Context window as primary state store
- Self-grading production loops
- Full GraphRAG rebuild as default update path
- Free-form inter-agent chat without typed payloads
- Infinite remediation loops without turn caps
- Mass-firing agents on short demos without cost-normalized fitness
