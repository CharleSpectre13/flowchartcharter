# Playbook Creation v1
House score. One named repeating job becomes a playbook, then a loop, then live. Nothing skips a cue.

## Two contracts (separate, both required)
1. @House Contract + @Christ Discernment — moral structure
2. @FlowChart Charter Engineer — path (one job, then stop)

## Three skills on every handoff
1. @Executive Comms Protocol — one ask, name job / path / done, report to CoS
2. @Rhythm Marker Validator — mark before send; unmarked stays out of Monday pack
3. @Loop Engineer — design the loop before it runs; no live loop until Deep Research receipt + CoS sign

## Cues
- Charles or CoS names the job.
- Owner writes the playbook in an isolated file.
- Owner fills Loop Engineer fields (design only).
- Deep Research runs on that playbook (named job only).
- CoS signs the receipt (Checker suspended).
- Then the loop may go live.

## Extra
If it is not the named job, write it as a list item only at https://github.com/CharleSpectre13/flowchartcharter. Do not execute it.

budget · schema · fear
